# F1: a simpler Force Feedback screen

Run #78 (`a247f0e`) brought us back to a build that launches, starts races and drives. The isolated R3A build (`016e002`) then made the existing Reference+ presentation the fresh-install default, and that combination was physically validated. F1 starts there. The later Experience/Unlock work and its race-start failures remain in the history, but none of that runtime code is included here. Unlock All is deferred from v1. The controller menu is frozen; this pass is only about how a player finds and understands FFB.

The normal FFB screen now shows the active profile, the existing master strength and the resolved wheel's friendly name and connection status. It is not a device picker. Reference+ is the intended player presentation. Reference remains the existing comparison/fallback behavior; internal mode names, M4/M5, Presence and Contrast are not shown as player controls. The legacy FFB on/off and raw device-ID fields are hidden from the generic Settings screen. A former `WheelFFBEnabled=false` override can be recovered through FFB Reset to Defaults without asking the player to edit an INI.

Advanced Force Feedback has three honest channel controls. Steering Load maps only to the existing spring setting, Road Detail to the existing road setting, and Impact to the existing impact setting. Each displays 100% at its established default. There is no independent wheel-vibration gain in this foundation, so a Vibration slider would be misleading and is deferred. Existing damping and grip-loss values are not retuned or recalculated.

The information icon appears only beside controls whose effect needs explaining. Its text describes what the current code actually does; there is no icon on the wheel identifier, tests, re-detect or reset. Invert Wheel uses the existing single inversion path. Left/Right remain the established 350 ms DirectInput tests, with a hard 20% normalized request ceiling regardless of master strength; this is a diagnostic output ceiling, not a claim about physical torque. Physical testing must confirm the left/right labels on the attached wheel, including with inversion enabled.

Re-detect calls the existing DirectInput refresh and fallback path. It does not solve duplicate wheel interfaces, stable endpoint identity or reconnect; those belong to F2. Reset restores the player-facing Reference+ selectors, 70% master strength, the three visible channel defaults, and Invert Wheel Off. It also clears a legacy disabled-FFB override. It does not reset controller bindings, telemetry, M5 mode, damping, grip loss or other unrelated settings.

The Force composer, presentation equations, output conditioning, road/impact/vibration calculations, wheel drive path, and native hooks are unchanged from R3A. The controller UI function is unchanged. This is an overlay presentation pass, with existing settings as its backing values.
