# Windows hardware validation

1. Start the utility with the wheel, pedals, shifter, and any button boxes connected.
2. Select **Initialize Devices** and confirm startup itself produces no motor force. Verify the progress screen runs all four SDL sessions automatically, shows real stage progress, and then performs native DirectInput FFB discovery.
3. Confirm completion opens the Quick Setup confirmation without beginning input capture. Return to **Devices**, select **Re-run Backend Tests**, and confirm the same four-session progress UI runs while the previous published results remain visible until replacement results are complete.
4. Confirm any delayed T300RS arrival appears under the specific backend that observed it.
5. On a Fanatec DD2, record every SDL and DirectInput interface shown. Verify the labels remain distinct, then use **Input Test** to identify which interface reports steering movement.
6. Confirm initialization offers **Start Quick Setup** and **Not Now** without capturing. Complete all seven gameplay bindings using the six-second windows. Exercise Retry, Skip, Back, and Cancel, then combine a wheel, separate pedals, shifter, and button box in one profile. Confirm the automatically resolved FFB endpoint appears separately. Run or skip the optional FFB check; verify its 3-2-1 countdown, bounded automatic shake, Yes/No/Skip response, and restart persistence.
7. Use **Input Test** to move every axis, button, and POV on every interface. Note whether each is detected-but-inactive or responsive.
8. On **FFB Test**, verify the sole FFB endpoint is selected automatically, or that ambiguous endpoints require confirmation. Verify motor output remains off until authorization. Confirm Strength places 20% at the far left and 100% at the far right, while the effective physical-test limit remains clearly shown as 20%. Hold **Test Left** and **Test Right**, release each, and verify output stops immediately. Enable **Invert FFB**, confirm both directions reverse without changing strength, then disable it.
9. Hold **Hold to Shake** briefly and confirm alternating left/right output uses the shared Strength request and stops on release. Run the existing FFB Test **Re-detect** and confirm active output stops, authorization is disarmed, SDL input refresh completes before native FFB is reacquired, the exact previous FFB identity is restored, and no torque is generated. Confirm a missing previous GUID reports unavailable and does not select another interface. Re-authorize, then repeat Left, Right, and Shake to verify output recovery. Move the assigned steering axis again to restore readiness. Repeat focus-loss, timeout, and device-disconnect shutdown checks at the lowest practical wheelbase hardware gain.
10. Export a report, confirm the success dialog names the TXT file, open the resolved Exports folder, and preserve both identically based TXT/JSON files.
11. Select **Compare FFB Response** and verify the software assessment completes without motor output. Confirm the 3-2-1 countdown and automatic Legacy test, then verify output stops, its timer freezes, and **Yes / No / Unsure**, **Retry Test**, and **Confirm & Next** appear. Confirm retry repeats only Legacy. Continue through the one-second zero-force Safety Interval, then repeat the checks for Dynamic using **Finish**. Confirm STOP appears only while an automatic stage can run and that focus loss, disconnect, and watchdog abort remaining stages. Verify results and the export keep commands accepted/method unsuccessful/interrupted/inconclusive separate from each method's physical confirmation.
12. Export after both methods. Confirm the TXT summary says **Current Output: Stopped** and **Session Output History: Output requested during session**. Confirm Legacy/Dynamic API outcomes and Yes/No/Unsure observations match the UI, simulated rows are labeled software assessment, and physical rows list stop/release/replacement/final-cleanup separately. Confirm JSON contains the same summary values under `summary` and retains schema `HYP36R_DEVICE_DIAGNOSTICS_V1`.
13. Open **Loaded Steering Response** directly. Confirm it displays the Quick Setup Steering device and axis without redundant selectors and does not alter the binding. Verify live normalized position follows only that axis. Confirm pedal, shifter, button, and unrelated-device activity cannot establish readiness; small idle noise below 2500 raw units is rejected. Re-run Quick Setup with a changed steering assignment, or disconnect/re-detect the assigned device, and confirm earlier activity is invalidated before moving the assigned axis left and right until **Activity: Detected** appears.
14. Confirm START TEST remains unavailable until the selected steering axis has verified movement, the independently selected FFB endpoint is ready, and no conflicting test is active. Select a turn direction, choose **START TEST** for Legacy, and confirm the six-second countdown produces no motor output while STOP and Escape remain available. Verify the active timer starts only when output begins, runs for at most 15 seconds, and repeats the same gradual one-direction envelope without spikes or reversal.
15. Record Yes/No/Unsure, one or more sensations, and one or more timing phases. Confirm all three visible Unsure controls operate independently; timing **Unsure** clears specific phases and selecting a specific phase clears timing Unsure. Confirm zero force persists for at least one second, Dynamic returns to READY, and Dynamic requires its own START TEST selection and countdown. Select **Reset Test** during preparation, active output, feedback, and completed results; confirm output stops, results clear, Test 1 returns, steering/FFB/direction remain selected, and no force starts until a fresh START TEST. Exercise STOP, Escape, focus loss, selected-input disconnect, FFB disconnect, and watchdog shutdown. Export TXT/JSON and confirm P11-E records assignment/readiness, rediscovery/reset events, 15-second duration, repetition boundaries, actual intervals, API/lifecycle evidence, safety interruption, sensations, and explicit timing uncertainty. Confirm both methods peak at no more than 20% nominal. Perform this controlled UAT on DD2 and RS50 only at a conservative wheelbase torque setting.
